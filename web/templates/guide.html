หน้าต่างๆ

ตั้งค่า
กำหนดวันที่ต้องการดูข้อมูล และจำนวนรถตู้ที่ต้องใช้ต่อวัน (เปลี่ยนวันที่ได้จากแถบด้านบนทุกหน้า)
รายชื่อรถตู้
ข้อมูลรถทุกคัน + วันที่เริ่มวิ่ง + วันลา + ลำดับคิวและคำแนะนำที่คำนวณอัตโนมัติ
บันทึกการวิ่ง
บันทึกทุกวันว่ารถคันไหนวิ่ง (เลือกรหัสจากรายการ — ชื่อคนขับขึ้นเอง)
แนะนำรถวิ่งวันนี้
คิวรถเรียงตามลำดับที่ควรได้วิ่ง รถที่ไม่พร้อม (ซ่อม/ลา/ยังไม่เริ่มงาน) อยู่ท้ายตารางเสมอ · ติ๊กเลือกแล้วกด "บันทึกว่าวิ่งแล้ว" ได้ทันที
Dashboard
สรุปภาพรวม กราฟ ตัวชี้วัดความสมดุล และจำนวนแถวบันทึกที่มีปัญหา

วิธีจัดคิว (คิววนตามหมายเลขรถ)

ลำดับคิว
วิ่งวนตามหมายเลขรถ 1 → 2 → 3 … ถึงคันสุดท้ายแล้ววนกลับไปคันที่ 1 วันถัดไปเริ่มต่อจากรถคันสุดท้ายที่วิ่งในวันล่าสุดของบันทึก (ดูหมายเลขในหน้าตั้งค่า) ไม่ดูว่ารถคันไหนรอมานานแค่ไหน
วันอ้างอิงคิว
แสดงวันที่วิ่งล่าสุดไว้ดูอย่างเดียว ไม่ใช้จัดคิว
รถใหม่
เข้าคิวตามหมายเลขของตัวเอง ได้วิ่งเมื่อคิววนมาถึงเลขนั้น
รถที่ถึงคิวแต่ไม่ได้วิ่ง
รถพร้อมวิ่งแต่ถูกข้าม (เช่น ไม่ตรงโซน) ไม่ได้วิ่งก่อนในวันถัดไป ต้องรอคิววนกลับมาถึงเลขตัวเองรอบหน้า
รถกลับจากลา/ซ่อม
ถูกข้ามระหว่างที่ไม่พร้อม กลับมาแล้วรอให้คิววนมาถึงเลขตัวเอง
หน้างานสลับรถ
ระบบอ่านจากบันทึกจริงทุกครั้ง ถ้าส่งคันอื่นแทน คิววันพรุ่งนี้ปรับตามจริงเอง
การจัด "ควรวิ่ง"
คัดเฉพาะรถที่พร้อมวิ่งก่อน แล้วเลือก N คันแรกในคิวตามจำนวนในหน้าตั้งค่า — รถซ่อม/ลาไม่กินโควตา
อัตราเฉลี่ยเที่ยว/วัน
คำนวณไว้ดูความสมดุลใน Dashboard (เที่ยวเดือนนี้ ÷ วันให้บริการ หักวันลา) แต่ไม่ใช้จัดคิว

วิธีใช้งานประจำวัน

  1. บันทึกรถที่วิ่งใน บันทึกการวิ่ง หรือติ๊กเลือกในหน้า แนะนำรถวิ่งวันนี้ แล้วกด "บันทึกว่าวิ่งแล้ว"
  2. ถ้าคอลัมน์ "ตรวจสอบ" ขึ้นข้อความสีแดง ให้แก้แถวนั้นก่อน (รหัสผิด / ซ้ำ / วิ่งก่อนวันเริ่มงาน)
  3. คนขับลา: กรอกวันเริ่มลาและวันสิ้นสุดลาในหน้าแก้ไขรถตู้ (สถานะรถยังเป็น "ใช้งานได้" ได้)
  4. กด › ที่แถบวันที่ด้านบนเพื่อไปวันถัดไป แล้วเปิด "แนะนำรถวิ่งวันนี้"

เที่ยววิ่งนับเฉพาะสถานะ "วิ่งแล้ว" ที่วันที่ก่อนวันที่จัดรถ (ถึงเมื่อวาน)
